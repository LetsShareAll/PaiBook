# PaiBook · 派书

> 不是应急食品，是应急手册！

米哈游三款游戏的攻略站：《原神》《崩坏：星穹铁道》《绝区零》。每个游戏一个独立的站点（各自的入口与主题），共享同一套数据模型与后端。

长标题：Paimon EmergencyBook · 派蒙的应急手册

## 站点

| Site              | 路径                 |
| ----------------- | -------------------- |
| 原神              | `/genshin`           |
| 崩坏：星穹铁道    | `/honkaistarrail`    |
| 绝区零            | `/zenlesszonezero`   |

技术栈：Vue 3 + Nuxt（SSR）· Cloudflare Workers + Hono + D1 + R2 · pnpm workspace。站点尚未开始实现。

## 仓库内容

- `CONTEXT.md` —— 领域词汇表（Game / Site / Entity / Guide / Draft / Link / Version / Profile）
- `docs/adr/` —— 架构决策记录
- `docs/agents/` —— 给 AI 代理的仓库约定

# 用户档案只存在客户端

「我的档案」（访问者自己的账号角色情况等）只存在浏览器 IndexedDB，支持带 schema 版本号的 JSON 导入 / 导出，服务端不存储任何用户数据；cookie 仅用于后台登录态（HttpOnly）与主题偏好，不设用户标识 cookie。档案一期只用于攻略的过滤与排序。

这样换来的是：没有账号体系、没有服务端用户数据泄露面，也不需要 cookie 同意横幅。将来若要做云同步，那等于新增一个"服务端存储用户数据"的决定，必须另开 ADR——这条边界不要悄悄跨过去。

## Considered Options

- 档案存 cookie：4KB 上限、每个请求都携带、隐私面上更敏感。
- 服务端账号体系：与"服务端不存储用户数据"直接冲突。

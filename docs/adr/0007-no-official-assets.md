# 不使用官方美术素材与游戏内字体

站点复刻游戏 UI 的**构件语言**——面板、按钮、选项卡、动效的形态与手感——但所有图标、纹样、背景一律自绘，绝不使用官方 logo、立绘或 UI 截图；字体只用许可证明确的 OFL / 免费商用字体（思源黑体、得意黑、未来荧黑、MiSans），绝不自托管游戏内字体文件。配合页脚常驻的非官方声明与"完全免费"承诺（无广告、无打赏、无会员）。

理由：三份官方同人指引都没有授权把官方素材放上网站，星铁指引还明确排除纯搬运，并自认其声明"不构成法律意义上的许可"——官方容忍不等于授权。

## Consequences

- 三个站点的视觉差异只能靠自绘资产与字体/配色/动效拉开，这会显著增加设计工作量。这是刻意的代价。
- 因为承诺非商业，引用 CC BY-NC-SA 来源的内容才成立；一旦要变现，必须先回头处理这件事。

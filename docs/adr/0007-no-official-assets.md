# 不使用官方美术素材与游戏内字体

站点复刻游戏 UI 的**构件语言**——面板、按钮、选项卡、动效的形态与手感——但所有图标、纹样、背景一律自绘，绝不使用官方 logo、立绘或 UI 截图；绝不打包或自托管游戏内字体文件。配合页脚常驻的非官方声明与"完全免费"承诺（无广告、无打赏、无会员）。

理由：三份官方同人指引都没有授权把官方素材放上网站，星铁指引还明确排除纯搬运，并自认其声明"不构成法律意义上的许可"——官方容忍不等于授权。

## 字体策略（实测订正）

最初接 `@nuxt/fonts`（Google Fonts 的 Noto Sans/Serif SC），但它在这套配置下只生成空 CSS——页面实际用的是系统字体，等于留了个"看起来配好、其实没生效"的陷阱。已移除该模块，改为：

- 正文走系统 CJK 字体栈（`PingFang SC` / `Hiragino Sans GB` / `Microsoft YaHei` / `system-ui`），标题另加 `Songti SC` / `SimSun` 等衬线兜底。
- **不打包任何 webfont**：游戏内字体不可用，而 CJK webfont 动辄数 MB，对攻略站不值得。
- 将来若确要统一观感，再自托管 OFL 子集字体（思源黑体 / 得意黑等）——那是一次独立的、有明确收益的决定。

## Consequences

- 三个站点的视觉差异靠自绘资产、配色与动效拉开，这会显著增加设计工作量。这是刻意的代价。
- 因为承诺非商业，引用 CC BY-NC-SA 来源的内容才成立；一旦要变现，必须先回头处理这件事。
- 字体在不同操作系统上会略有差异（这是显式接受的代价，不是疏漏）。
